═══════════════════════════════════════════════════════════════════

SOLUÇÃO 1: CORRIGIR PERMISSÕES VIA FTP/cPanel
═══════════════════════════════════════════════════════════════════

1. Entre no FTP ou Gerenciador de Arquivos do cPanel

2. PERMISSÕES DOS ARQUIVOS (clique direito > Permissões):

   Arquivos HTML/TXT/HTACCESS:
   ✓ .htaccess          → 644
   ✓ index.html         → 644
   ✓ diagnostico.html   → 644
   ✓ favicon.png        → 644
   ✓ logo-mix-mateus.png → 644

   Pasta assets:
   ✓ assets/ (pasta)    → 755
   ✓ Todos os arquivos dentro → 644

3. CHMOD em números:
   - Arquivos: 644 (rw-r--r--)
   - Pastas: 755 (rwxr-xr-x)

═══════════════════════════════════════════════════════════════════

SOLUÇÃO 2: CORRIGIR VIA LINHA DE COMANDO (SSH)
═══════════════════════════════════════════════════════════════════

Se tiver acesso SSH, rode estes comandos:

cd public_html  # ou o diretório onde estão os arquivos

# Ajustar permissões das pastas
find . -type d -exec chmod 755 {} \;

# Ajustar permissões dos arquivos
find . -type f -exec chmod 644 {} \;

# Verificar se deu certo
ls -la
