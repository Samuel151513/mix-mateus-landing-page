🚀 NOVO: INTEGRAÇÃO COM API ViaCEP!

✅ Busca automática de endereço por CEP!

Funcionamento:

1. Usuário digita o CEP (formatação automática: 00000-000)

2. Ao completar 8 dígitos → Busca automática na API ViaCEP

3. Campos preenchidos automaticamente:

• Rua
• Bairro
• Cidade
• Estado

4. Loading spinner enquanto busca

5. Toast de confirmação: "CEP encontrado!"

6. Tratamento de erros: CEP inválido ou não encontrado

⚡ 100% GRÁTIS - Sem autenticação necessária!

🔧 DETALHES TÉCNICOS DA API

API Utilizada: ViaCEP (https://viacep.com.br/)

Endpoint: https://viacep.com.br/ws/{cep}/json/

Método: GET

Autenticação: Nenhuma (100% grátis)

Resposta: JSON com dados do endereço

Campos retornados:

• cep: "01001-000"
• logradouro: "Praça da Sé"
• complemento: "lado ímpar"
• bairro: "Sé"
• localidade: "São Paulo"
• uf: "SP"
• ibge: "3550308"
• gia: "1004"

Tratamento de Erros:

• CEP inválido: Toast "CEP não encontrado"

• Erro de conexão: Toast "Erro ao buscar CEP"

• Resposta com erro: {"erro": true}
